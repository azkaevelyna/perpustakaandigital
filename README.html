# 🌷 Petal Pages | Digital Library *A little place for lovely reads and endless discoveries.* Petal Pages merupakan perpustakaan digital yang menyediakan berbagai koleksi buku elektronik (e-book) sebagai sumber bacaan dan informasi untuk menambah wawasan serta mendukung kebutuhan belajar. Repository ini dibuat untuk memenuhi tugas praktik GitHub sekaligus menjadi ruang penyimpanan dan akses koleksi e-book secara digital. ## 🎀 Repository Contents - `ebook/` : Berisi 10 koleksi buku elektronik dalam format PDF yang dapat dibaca secara digital. - `metadata/` : Berisi informasi bibliografi dari setiap koleksi buku. - `index.html` : Halaman utama perpustakaan digital Petal Pages. - `README.md` : Berisi informasi dan deskripsi repository. ## 📚 E-Book Collection Terdapat 10 judul buku yang dapat diakses melalui halaman utama Petal Pages. ## 🌼 UGC Learning Corner Dokumentasi ringkasan pemaparan User Generated Content (UGC) beserta wawasan baru yang diperoleh dari kegiatan pembelajaran tersedia pada tautan nomor 11 di halaman utama. ## ♡ About This Project **Project:** Digital Library **Platform:** GitHub **Year:** 2026 *Made with love, a little knowledge, and lots of stories. ♡*
